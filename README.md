# 蔡恒立 · 个人学术主页

江西水利电力大学土木工程教研室讲师蔡恒立的个人学术主页，基于个人简历整理，用于展示
个人经历、研究方向、学术成果与联系方式。

## 文件结构

```
index.html        页面内容（个人信息、论文、项目等都写在这里）
css/style.css     页面样式（主题色在文件开头 :root 变量中调整）
js/main.js        交互脚本（导航高亮、标签页、滚动动画）
assets/           图片资源（头像与研究配图）
```

## 如何更新内容

1. 用记事本或 VS Code 打开 `index.html`，修改对应的文字内容；
2. 替换或增删论文、项目、获奖条目时，参照已有条目的格式复制修改即可；
3. 修改完成后，直接用浏览器打开 `index.html` 预览；
4. 确认无误后，将改动推送（或重新上传）到本仓库。

## 发布到 Gitee Pages

1. 进入 Gitee 仓库页面，点击「服务」→「Gitee Pages」；
2. 部署分支选择 `master`，目录选择 `/`（根目录），点击「启动」；
3. 等待部署完成后，即可通过 `https://cai-hengli.gitee.io/biographical-notes/` 访问；
4. 每次更新内容后，在 Gitee Pages 页面点击「更新」重新部署即可。

> 提示：Gitee Pages 需要账号完成实名认证；部署服务偶尔需要手动点击“更新”才会生效。
